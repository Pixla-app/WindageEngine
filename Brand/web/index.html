A game is a Swift file

The engine owns when. Your game owns what.

Pacing, frames in flight and the fixed timestep are the engine's. Your pipelines, your draws and your rules are yours — the line sits exactly where every renderer it came from stopped being the same.

import Metal
import WindageEngine

final class Game: GameLoop {
    var body = CharacterController(feet: .zero)
    var world = CharacterController.Surroundings()

    func beginFrame() {}

    func step(deltaTime: Float) {
        body.step(yaw: 0, input: MovementInput(forward: 1),
                  deltaTime: deltaTime, in: world)
    }

    func viewportSizeChanged(width: Int, height: Int) {}

    func encode(into encoder: MTL4RenderCommandEncoder,
                frameSlot: Int, interpolation: Float) {
        // your pipelines, your draws
    }
}

The whole contract: GameLoop. Everything above it is the engine's.

Shows its work

A game engine that shows its work.

Every feature was pulled out of a working game, and every claim on this page is a number you can reproduce on your own machine — before and after, in the changelog, with the check that holds it.

A game stepping at 60 used to miss a ledge one at 120 cleared. Now one course of walking, jumping, sliding and landing ends in the same place at all four rates.

Found by drawing one frame

Every shadow was a frame stale.

The scene read shadow maps that the same command buffer was still writing. In play it looked right — last frame's maps were there — and nothing said otherwise.

Drawing a single frame into a file showed it: the first frame came out different every run. Two barriers later, four runs of that frame are the same bytes, and the frame is a check.

What's in it

What a native Mac game needs to ship, and was identical every time somebody wrote it.

Frame pacing

Frames in flight, a fixed timestep, a clock that keeps time with the window hidden.

FrameRenderer · FixedTimestep

Light and shadow

Cascaded sun shadows, and spot and point lights binned into clusters that each cast.

ShadowCascades · ClusteredLights

Characters

Skinned animation from USD, cross-fades, and things hung off joints.

SkeletonPose · TransformHierarchy

A body with feet

Stairs, lifts, turntables, being pushed — and the same at any step rate.

CharacterController

Levels

A versioned level format, and an editor you use inside your running game.

Level · LevelEditor

Sound, input, settings

Positional audio, keys and pads a player rebinds, settings that save.

AudioEngine · InputBindings

Many copies

Instanced drawing: a wood of trees or a field of debris in one draw per kind.

InstanceBatches · InstanceBuffer

Detail by distance

Simpler versions of every mesh, made when it loads; each copy draws the one its distance earns.

MeshDetail

What it deliberately isn't

Each of these is something the engine leaves to you, or to a game that proves it is needed.

No scene graph

Your game owns its objects. The engine owns when things happen.

No ECS

Structure your game the way your game wants to be structured.

No editor inside the engine

A level editor embeds in your game and edits its levels in place. A standalone editor is a separate product built on the engine, not part of it.

Not a runtime

Mac first. Another platform means a native port, not a wrapper.
